# Especialidades → sistemas → conceptos STEM

**Origen:** mapa neutralizado a partir de `02.1.2_MANUAL_DE_ROLES_TACTICOS_V1.2` y del CSV
`Sistemas Submarinos por Compartimentos`. El manual original es belicista y está obsoleto
como doctrina; de él solo se conserva el reparto de sistemas por especialidad, reescrito
en clave civil. La rama "1.2 Armamento" queda excluida.

**Uso:** insumo para asignar las 3 variantes de cada celda de la grilla 5×5 de Cobre
(especialidad × disciplina STEM) y para escribir las guías de temas de cada episodio.

## Notas de uso

- En Acero este mapa sirve para el recorrido patrimonial (sin preguntas TIMSS).
- En Cobre define qué sistemas pueden dar contexto a cada celda y qué disciplinas son
  candidatas naturales.
- Una misma pregunta puede servir a dos especialidades si el sistema es compartido
  (ej.: ecosonda en NAV y ELN); se elige una celda principal y se justifica.
